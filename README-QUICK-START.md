# 🐾 Pet Food Shop - Quick Start

## 🚀 ติดตั้งง่ายๆ ไฟล์เดียวจบ!

### Windows:
```cmd
install-pet-shop.bat
```

### Linux/macOS:
```bash
bash install-pet-shop.sh
```

## 🎮 เมนูที่จะเห็น:

```
1) 🐳 Docker (แนะนำ)    → http://localhost:8000
2) 📁 XAMPP             → http://localhost/pet-food-store  
3) ❓ ตรวจสอบระบบ
4) 🚪 ออก
```

## ✅ ผลลัพธ์:
- WordPress + WooCommerce
- ธีม Pet Paws 
- สกุลเงินไทย (THB)
- สินค้าตัวอย่าง
- Admin: admin/admin123

## 🔧 ความต้องการ:
- **Docker:** Docker Desktop
- **XAMPP:** Apache + MySQL + PHP
